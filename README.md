# MechanicsHW1 — домашние задания 1 и 2

Учебный проект на **Unreal Engine 5.8**. ДЗ 1 добавляет спринт, взаимодействие и выносливость. ДЗ 2 добавляет арену с процедурными препятствиями и охранника с Behavior Tree.

## ДЗ 1. Персонаж и Enhanced Input

- **C++-персонаж** `AMechanicsHW1Character`, наследующий `ACharacter`. Blueprint `BP_ThirdPersonCharacter` использует этот класс в качестве родительского.
- **Enhanced Input**: отдельные `IA_Sprint` и `IA_Interact`, назначенные в `IMC_Default`.
- **Спринт**: изменение `MaxWalkSpeed` при удержании и отпускании Shift; флаг `bIsSprinting` доступен в Blueprint.
- **Взаимодействие**: `Dynamic Multicast Delegate`, вызываемый в C++ при нажатии E. В Blueprint событие выводит `Interaction triggered!`.
- **Анимация**: `ABP_MechanicsHW1` с состоянием `Sprint` и двусторонними переходами между `Walk / Run` и `Sprint` по `bIsSprinting`.
- **Stamina**: запас выносливости убывает при спринте, восстанавливается вне спринта и отображается на экране; при нулевом значении спринт автоматически выключается.

## Управление

| Клавиша | Действие |
| --- | --- |
| W / A / S / D | Передвижение |
| Мышь | Обзор камеры |
| Space | Прыжок |
| Left Shift (удерживать) | Спринт с расходом Stamina |
| E | Взаимодействие (`Interaction triggered!`) |

## Как открыть проект

1. Установить Unreal Engine 5.8 и компоненты C++ для Visual Studio 2022.
2. Клонировать репозиторий или скачать его архивом.
3. Открыть `MechanicsHW1.uproject` и разрешить сборку модулей проекта, если будет предложено.
4. Открыть `Content/ThirdPerson/Lvl_HW2_PCG`, если уровень ещё не открыт, и нажать **Play**. Исходная карта ДЗ 1 доступна как `Lvl_ThirdPerson`.

## Проверка ДЗ 1

- WASD, камера и прыжок работают как в стандартном шаблоне.
- Shift увеличивает скорость и постепенно расходует Stamina.
- При Stamina = 0 спринт прекращается; после отпускания Shift Stamina восстанавливается.
- Нажатие E выводит сообщение `Interaction triggered!`.
- Анимация переключается между обычным движением и Sprint.

## ДЗ 2. PCG и Behavior Tree

`PCG_Obstacles` сэмплирует поверхность арены, прореживает точки и подбирает для каждой размер, поворот и один из трёх мешей. При текущем seed граф создаёт 50 препятствий. `PCGVolume` хранит результат генерации. У экземпляров есть коллизия, а `NavMeshBoundsVolume` охватывает арену. NavMesh учитывает препятствия, в том числе после повторной генерации.

`AHW2GuardController` запускает `BT_HW2Guard` и `BB_HW2Guard` у персонажа `AHW2GuardCharacter`. Дерево выбирает ветвь в порядке приоритета: преследование, поиск, патрулирование. Декораторы Blackboard прерывают текущую ветвь при появлении или потере цели. В каждой ветви используется навигационный `Move To`.

### Дополнительная логика для критериев 9–10

- `BTService_HW2Awareness` проверяет направление взгляда, дистанцию и прямую видимость. Подозрение растёт быстрее вблизи. Когда `Suspicion` достигает 1, охранник начинает преследование. При потере видимости он около пяти секунд ищет игрока у последней видимой позиции, затем возвращается к патрулю.
- Сервис учитывает шаги из ДЗ 1 только при движении по земле с активным спринтом. Охранник слышит их даже за укрытием и проверяет место шума. Для начала погони ему всё равно нужно увидеть игрока.
- `BTTask_HW2SearchPoint` сначала выбирает достижимую точку у источника шума или последней встречи, затем расширяет область поиска. `BTTask_HW2PatrolPoint` выбирает случайную достижимую точку вокруг места появления охранника.

### Как проверить ДЗ 2

1. Выберите `PCGVolume` на карте `Lvl_HW2_PCG` и нажмите **Generate**. Убедитесь, что появились кубы, цилиндры и блоки со скошенными гранями. Нажмите **P**, чтобы увидеть NavMesh и вырезы вокруг препятствий.
2. Запустите **Play** и держитесь вне поля зрения охранника. Он выбирает новые точки патруля и обходит препятствия. Для отладки откройте `BT_HW2Guard` и выберите охранника в **Debug Object**. Активную ветвь также можно увидеть в Gameplay Debugger через клавишу апострофа и **NumPad 2**.
3. Выйдите перед охранником на открытое место. В Blackboard сначала растёт `Suspicion`, затем заполняется `TargetActor` и включается погоня. Скройтесь за укрытием и отойдите. После поиска у последней точки встречи охранник вернётся к патрулю.
4. Пробегите с **Shift** за укрытием или позади охранника в пределах примерно 18 м. Появится `SearchOrigin`, охранник начнёт проверять место шума. Пока он не увидел игрока, `TargetActor` остаётся пустым. Повторите маршрут шагом для сравнения.
