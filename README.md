# MechanicsHW1 — расширение Third Person Template

Учебный проект на **Unreal Engine 5.8 (C++ / Enhanced Input)**. Расширяет стандартный шаблон Third Person механиками спринта, взаимодействия и выносливости.

## Реализовано

- **C++-персонаж** `AMechanicsHW1Character`, наследующий `ACharacter`. Blueprint `BP_ThirdPersonCharacter` использует этот класс в качестве родительского.
- **Enhanced Input**: отдельные `IA_Sprint` и `IA_Interact`, назначенные в `IMC_Default`.
- **Спринт**: изменение `MaxWalkSpeed` при удержании и отпускании Shift; флаг `bIsSprinting` доступен в Blueprint.
- **Взаимодействие**: `Dynamic Multicast Delegate`, вызываемый в C++ при нажатии E. В Blueprint событие выводит `Interaction triggered!`.
- **Анимация**: `ABP_MechanicsHW1` с состоянием `Sprint` и двусторонними переходами между `Walk / Run` и `Sprint` по `bIsSprinting`.
- **Stamina**: запас выносливости убывает при спринте, восстанавливается вне спринта и отображается на экране; при нулевом значении спринт автоматически выключается.

## Управление

| Клавиша | Действие |
| --- | --- |
| W / A / S / D | Передвижение |
| Мышь | Обзор камеры |
| Space | Прыжок |
| Left Shift (удерживать) | Спринт с расходом Stamina |
| E | Взаимодействие (`Interaction triggered!`) |

## Как открыть проект

1. Установить Unreal Engine 5.8 и компоненты C++ для Visual Studio 2022.
2. Клонировать репозиторий или скачать его архивом.
3. Открыть `MechanicsHW1.uproject` и разрешить сборку модулей проекта, если будет предложено.
4. Открыть карту Third Person и нажать Play.

## Проверка

- WASD, камера и прыжок работают как в стандартном шаблоне.
- Shift увеличивает скорость и постепенно расходует Stamina.
- При Stamina = 0 спринт прекращается; после отпускания Shift Stamina восстанавливается.
- Нажатие E выводит сообщение `Interaction triggered!`.
- Анимация переключается между обычным движением и Sprint.
